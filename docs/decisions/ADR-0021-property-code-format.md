# ADR-0021: قالب کد ملک — حفظ قالب فعلی، تعویق پیشوند برند و دورهٔ شمسی

**تاریخ:** 2026-09-27
**وضعیت:** پذیرفته‌شده (موقت)

## زمینه
Business Source of Truth نمونهٔ `AB-ISF-MJ-AP-S-2608-00124` را آورده است (پیشوند برند سازمان + شهر + محله + نوع + معامله + دوره + شماره).
کد فعلی: `AREP-ISF-MJ-AP-S-2609-00003` — پیشوند ثابت `AREP` و دورهٔ `YYMM` میلادی. کدها در لینک عمومی (`/p/{code}`)، QR، پیام‌های تلگرام و علاقه‌مندی‌ها منتشر شده‌اند.

## تصمیم
- قالب فعلی حفظ می‌شود؛ ADR-0007 (جدایی شمارنده از قالب‌بندی) همچنان معتبر است، پس تغییر قالب بعداً بدون مهاجرت داده ممکن است.
- **تعویق:** (۱) پیشوند اختصاصی هر سازمان (مثلاً `AB`) نیازمند فیلد `code_prefix` در سازمان و تضمین یکتایی در سطح پلتفرم است؛ (۲) دورهٔ شمسی (`0507` به‌جای `2609`) نیازمند تصمیم مالک دربارهٔ مرز سال و تبدیل تقویم در سرور است.
- کدهای صادرشده هرگز تغییر نمی‌کنند (لینک‌های منتشرشده نشکنند).

## پیامدها
- وقتی مالک قالب نهایی را تأیید کند، فقط کدهای جدید با قالب جدید صادر می‌شوند و جستجو بر اساس کد برای هر دو قالب کار می‌کند.
