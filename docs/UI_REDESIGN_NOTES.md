## 3. معماری فرانت‌اند

```
src/
├── api.ts                    ← کلاینت API (بدون تغییر در قرارداد؛ فقط یک نوع پارامتر عمومی‌تر شد)
├── App.tsx                   ← مسیرها + دروازه سازمان + صفحه خطا
├── main.tsx                  ← Router + ThemeProvider + Toaster
├── index.css                 ← فونت self-hosted + توکن‌ها + قواعد پایه
├── lib/       cn | format (اعداد/قیمت/تاریخ فارسی) | types
├── state/     session (احراز هویت، سازمان، Outbox، PWA) | data (props/persons/visits/deals/…) | theme
├── components/ ui (Button, Card, Modal, Confirm, Badge, Stat, ScoreBar, Skeleton, EmptyState, Switch, …)
│               shell (Topbar, Sidebar, BottomNav, MoreSheet, OrgSwitcher)
└── features/  properties | crm | visits | deals | team | roles | ai | integrations
                public-list | public-property | admin (lazy) | misc (favorites + notifications)
```

### مسیرها

| مسیر | صفحه |
| --- | --- |
| `/` | املاک (فیلتر + جستجو + ساخت) |
| `/crm`, `/visits`, `/deals` | مشتریان، بازدیدها، پایپ‌لاین معاملات |
| `/team`, `/roles` | دعوت‌نامه‌ها و RBAC |
| `/ai`, `/integrations` | هوش مصنوعی و یکپارچه‌سازی |
| `/favorites`, `/notifications`, `/public` | علاقه‌مندی‌ها، اعلان‌ها، املاک منتشرشده |
| `/admin` | سوپر ادمین (Lazy-loaded، شامل recharts) |
| `/p/:code` | صفحه عمومی ملک، **بدون احراز هویت** |
| `/d/:code` | سازگاری با لینک قدیمی → هدایت به معاملات |
| `/?view=public&code=…` | سازگاری با لینک قدیمی → هدایت به `/p/:code` |

`tailwindcss` + `postcss` + `autoprefixer` • `lucide-react` (آیکون) • `sonner` (توست) • `react-router-dom@7` • `recharts` (نمودار ادمین، در chunk جدا) • `vitest` + `@testing-library/react` (تست)

## 4. چه چیزهایی بهبود یافت (تجربه کاربری)

1. **پوسته اپ:** نوار بالا (نام برند، وضعیت آنلاین/آفلاین، شمارنده Outbox، نصب PWA، تغییر تم، زنگ اعلان با شمارنده، چیپ سازمان) + **Bottom Navigation** موبایل با ۵ مقصد و شیت «بیشتر» + **Sidebar** دسکتاپ.
2. **حالت‌های خالی/بارگذاری/خطا:** هر لیست Skeleton مخصوص خود را دارد، حالت خالی با راهنما و CTA، و خطا با دکمه تلاش مجدد. هیچ لیستی «سفید» نمی‌ماند.
3. **مودال‌ها:** همه فرم‌ها به مودال منتقل شدند (به‌جای فرم‌های درون‌صفحه‌ای)، با انیمیشن، بسته‌شدن با Escape و کلیک بیرون.
4. **دروازه سازمان:** به‌جای `prompt()`، صفحه انتخاب سازمان با کارت‌های سازمان و مودال ساخت سازمان (نام + slug).
5. **معاملات:** بصری‌سازی پایپ‌لاین (۷ مرحله) + نوار پیشرفت + دکمه «مرحله بعد» با قفل نسخه (Optimistic Locking) و پیام اختصاصی خطای ۴۰۹ + **تاریخچه به‌صورت تایم‌لاین** (قبلاً `alert`).
6. **تطبیق AI:** نوار امتیاز رنگی (۰٫۹۵ → سبز)، دلایل فارسی به‌صورت چیپ، و درخواست‌ها/املاک قابل انتخاب با یک کلیک.
7. **یکپارچه‌سازی:** به ۶ تب تقسیم شد (تلگرام، پیامک، آگهی، پرداخت، نقشه، لاگ) با خروجی JSON تاشو و لینک‌های قابل کلیک.
8. **ادمین:** کارت‌های آماری + دو نمودار (توزیع موجودیت‌ها، مقایسه سازمان‌ها) + جدول کاربران با سوییچ سوپر ادمین.
9. **صفحه عمومی `/p/:code`:** طراحی لندینگ مستقل (هیرو، قیمت طلایی، مشخصات، اشتراک‌گذاری تلگرام، املاک مرتبط) با تزریق OG/JSON-LD مثل قبل.
10. **دسترس‌پذیری:** `aria-label` روی دکمه‌های آیکونی، فوکوس‌رینگ، کنتراست AA در هر دو تم، احترام به `prefers-color-scheme`، اهداف لمسی ≥ ۴۴px.
11. **کارایی:** تکه‌تکه‌سازی bundle (react / charts / app) → بار اول موبایل ~۱۱۴KB gzip؛ ارتفاع صفحه ادمین (recharts) فقط هنگام ورود به آن بارگذاری می‌شود.
12. **آفلاین:** فونت self-hosted + `offline.html` بازطراحی‌شده + صف Outbox با شمارنده در نوار بالا و دکمه همگام‌سازی.
